# 道光：0.12 造型依据与复原边界

适用场景：1836 年开局，目标年龄 53 岁。本文记录参考依据与本轮造型取舍，不作为相似度或运行测试验收结论。

## 历史来源支持什么

- **身份与年龄背景：**[故宫博物院《道光皇帝》](https://www.dpm.org.cn/court/lineage/226239.html)记载旻宁生于1782年，并提供明确标识人物的宫廷肖像。该页未注明所配肖像的创作年份，因此不能称它准确记录了1836年、53岁时的面貌。
- **清瘦的脸部结构：**故宫研究馆员关雪玲的[《清帝养生观探赜》](https://img.dpm.org.cn/Uploads/file/2025/01/06/1736130532ILCWarxVs260.pdf)（《紫禁城》2024年第12期，印刷页45–46）结合朝服像与文献，讨论道光面容清瘦、颧骨突出、两颊凹陷，以及早年已有清瘦记述。这支持减少饱满颊部；不支持据此给人物添加疾病、营养不良或特定健康诊断。
- **轮廓与须髭分布：**已查看[故宫所发布的肖像原图](https://img.dpm.org.cn/Uploads/Picture/2019/06/11/s5cff55db0c1c1.jpg)。图中下脸较收窄，须髭轻薄；可作为修正宽圆下脸和密集尖束胡须的依据。图像分辨率及绘画程式不足以确定毛发数量、毫米级脸部尺寸或自然肤色。
- **较早的形象参照：**[故宫名画记《清人画旻宁行健思藏像轴》](https://minghuaji.dpm.org.cn/paint/detail?id=af9ba29c17f94e37a5b532f60323c55d)将作品定年为1829年，比开局早七年。它可补充比较，但不能与年代未明的朝服像拼成一份“1836年精确面部扫描”。

## 本轮采用的造型方向

| 部位 | 0.12 的取舍及依据边界 |
|---|---|
| 脸型与年龄 | 收窄下脸、增加颧骨起伏与颧下凹陷，保留额部和颧弓的独立宽度；用体积变化表现中年后期，避免仅靠深色皱纹。清瘦方向有来源支持，具体程度属于艺术判断。 |
| 鼻与嘴 | 细化鼻翼、减薄唇部，改善当前过于圆润的口鼻体积；仍须结合正面与三分之四视角调整，不能将参数百分比当作史料测量。 |
| 眼睑与眼神 | 增加眼周组织层次，保留左右眼睑的小差异；独立眼骨控制轻微视线变化。该差异与动作是自然化设计，不是已证实的个人特征或习惯。 |
| 胡须 | 改为分簇、短而细的须髭，错开根部密度与末端，取消整束统一向中心收尖的“刷子”形。保留上唇髭与颏须的区别，不夸张为浓密长须。 |
| 皮肤 | 先保证细节法线接入脸部实际使用的材质，再调整局部粗糙度与眼周细节；不把绘画纸绢颜色直接当作真实肤色，也不以均匀噪声替代年龄结构。 |

**对外表述：**基于故宫肖像与文献制作的原创艺术复原。历史身份及年龄背景有依据；53岁时的精确容貌、毛发颜色比例、皮肤细节和眼部动作仍有不确定性。参考链接用于研究追溯，不代表已获画像纹理再发布授权。
