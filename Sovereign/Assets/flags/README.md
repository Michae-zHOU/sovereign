# 0.8 国家识别旗素材

本目录含12个模拟国家的13个SVG（美国24星、25星各一）。均来自下列Wikimedia Commons独立素材，不是从任何商业游戏提取。原SVG内容未修改，仅按游戏国家ID改名。SHA-256、原作者、来源、许可和年代说明见`provenance.json`。

## 年代与展示范围

旗帜用来识别游戏国家。清朝黄龙旗、德川白黑白旗、奥斯曼八角星旗及西班牙早期海军旗都有下面明确说明的年代/适用范围，不能把“有历史来源”理解为“1836年各国统一现行国旗的完全复原”。美国开局为24星，1836-07-04可切换25星；1837年以后后续增星不在本素材集内。

## 验证

13份SVG通过XML解析，未引用外部图片/脚本或网络字体，包含原鹰徽、龙纹与王冠盾徽，无文字占位。资源加载与实际小尺寸显示仍应随Godot导入和界面截图一起核对。
