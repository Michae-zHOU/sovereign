# 1815 年历史疆域参考图层

这是一张**1815 年参考地图**，不是 1836 年精确政治地图，也不会随游戏日期改变。界面须持续显示“疆域参考：1815年 · 非1836年精确边界”。底层地形与海岸线来自项目既有现代自然地理资料；历史岸线没有重建。

- 作者与来源：André Ourednik 及 historical-basemaps 贡献者，<https://github.com/aourednik/historical-basemaps>。
- 固定版本：`da7a4b735ecef70aebdc9c73e409d8a2500d50f3`，`geojson/world_1815.geojson`。
- 原数据与派生数据按随附 `LICENSE.txt`（GNU GPL v3）提供。保留原始 GeoJSON、版权来源和完整许可证；衍生图层不是 Victoria 3 的资产。
- 来源原文件 SHA-256：`fb654f734583f550904cfa45f361e395c1a488c4960050da2632cb2ac7d1cd1e`。

原始资料共 436 个 feature。按名称合并后为 313 个已命名条目及一个“历史归属未标注地区”条目。条目包含国家、殖民地、文化地区与原住民族范围；**313 不是独立国家数量，也不代表所有历史政权已经收录**。101 个原始 feature 未标注归属，保持未标注，不交给最近首都。

中文界面为主要政权与地区提供校译名称。151 个较小地区的专名仍待历史资料校译，暂显示“历史地区（编号）”；英文原始专名完整保留在 `SourceName` 与原始 GeoJSON，不能将编号当成历史地名。

已知限制：1815 年与 1836 年之间存在比利时独立、希腊独立、美洲独立运动等重大变化。场景中的比利时仍可经城市/首都图标选取，但本参考底图的疆域不会据此冒充已更新。原资料也存在概括、重叠和误差；香港在原资料中单列，本项目明确作为地理地区并关联大清，未将其视为独立国家。原资料的 `BORDERPRECISION` 不作为本项目的精确性保证。

## 数据转换和选择

`build_atlas.py` 从随附原始 GeoJSON 生成 `atlas_1815.json`、`territory_ids.png` 与 `provenance.json`。处理包括同名多面合并、英国两个名称合并、经度跨日界线展开、保留多边形内洞、坐标保留六位小数、中文名称与明确的场景关联。没有用现代国家边界替换历史边界。渲染使用 4096×2048 的国家索引纹理；R 通道存低 8 位、G 通道存高 8 位，必须最近邻采样，不作颜色空间转换。

鼠标射线与地形求交后，以经纬度执行多边形内点判定；5°空间格网仅加速候选查询。重叠时先选择已命名的较小地区，未标注地区最后处理。GPU 图层按同样顺序绘制；一个像素内的极小边界可能因分辨率量化而不同。独立首都图标有 12px 的显式命中范围，不能据此扩展为国土。

`HistoricalWorldAtlas` 仅保存参考资料。只有 `ScenarioCountryId` 关联既有国家模拟的条目会打开该国经济；其他地区打开资料查阅页，不生成虚假人口、财政或产值。

人口和经济地图视图的城市点大小来自当前 `CityState.Population` / `CityState.Gdp`，以平方根缩放并限制可视尺寸；城市标签显示真实场景值。这些是开发版模拟数值，并非历史人口普查统计。
