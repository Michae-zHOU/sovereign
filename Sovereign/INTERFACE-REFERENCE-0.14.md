# 0.14 界面实机对照记录

2026-09-20，根据用户授权，通过 computer-use 操作本机已打开的 Victoria 3 大清开局。关闭开局目标说明，依次查看政治、人口、建筑、外交；期间时间维持暂停。参考画面约为4096×1152，Sovereign常规验证为1600×1000，不能直接按屏幕宽度占比判断面板尺寸。

## 实际观察与本轮调整

| 页面 | 原版实际观察 | Sovereign本轮采用 |
| --- | --- | --- |
| 政治 | 全宽概览，领袖、集团/民意、政治状态分栏；集团用简明符号 | 增加三栏政治概览，沿用实时骨骼领袖；八集团使用独立物件图标，组阁卡片更紧凑 |
| 人口 | 窄面板内三个阶层人物栏，图像与收入、税负、需求并列 | 增加三个汇总阶层图文栏及切换，七职业详细卡片继续提供实际账目 |
| 建筑 | 紧凑建筑行：左缩略图，右名称/收益，下方生产方式与圆形扩建按钮 | 新场景图用于每类建筑，列表改左图右操作；选址、城市详情保留宽图 |
| 外交 | 国旗、地位、条约及国家导航形成层级；原版包含本作尚未实现的外交系统 | 为已有国家列表增加国旗卡、关系与条约状态、会谈图；继续连接已有三维会谈及提案 |

图片位置、信息密度与交互层级作为设计参考。本作使用原创插图、代码和游戏参数；没有提取原版纹理、人物模型或图标。新增插图的完整提示词和图集顺序见[资产说明](Assets/illustrations/panels/README.md)。

## 仍有差距

- 原版人口人物为三维，本轮人口卡使用二维职业插画；历史领袖继续使用已有的可动三维模型。
- 本作未实现原版政治运动、鼓动者、国家集团和完整外交博弈；页面只展示现有模拟产生的数据。
- 控件纹理、边框、地图细节、人物质量及整体美术仍与原版有明显差距，不能把本轮图文改进写成完全复刻。
- 清代风格的插画目前也被其他可玩国家共用；后续应按文化补齐，并加入更多不同性别与年龄的阶层表现。

交付截图来自实际Godot运行画面，见[0.14发行说明](RELEASE-0.14.md)。原版对照画面仅用于本机观察，未打包为游戏素材。
