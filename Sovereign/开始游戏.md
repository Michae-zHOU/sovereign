# 万国纪元 0.10：中文开始指南

完整解压 **Sovereign-Windows-0.10**，运行 `Sovereign.exe`，保留 `data_Sovereign_windows_x86_64` 文件夹。默认简体中文、大清开局，初始暂停。可经营 12 国、60 个场景地区、128 城，其中大清 40 城；当前时间范围为 1836—1846。

## 先观察，再推进一天

左栏提供朝政、政治、建筑、市场、人口、科技、外交、日志、地区和领袖。悬停图标显示名称；标题圆形“×”或 Esc 收起详情。空格暂停／继续，右上“+1天”只结算一天；弧形表盘 Ⅰ—Ⅴ 对应每秒 1、2、4、8、12 天。

0.10 不再以全国库存决定供需。先打开“市场 → 市场订单”，观察买单、卖单、价格偏离和短缺，再推进一天。商品价格、建筑收入与人口支出相互影响，不能仅凭增加建筑数量判断经营好坏。

## 大清的经营路线

1. **查看粮食与地方价格。** “朝政”可进入广州或全国市场；“市场 → 地区价格与接入”选择广东，对比当地与全国价格。缺乏基础设施会削弱市场接入。当前进出口方向由全国统一设置，尚无完整广州海关和世界贸易中心。
2. **检查苏州纺织厂。** “建筑”选择江苏，点击“纺织厂”名称展开城市。先看苏州的工资、利润、现金、债务与生产方式，再用“＋”选择建设城市。亏损建筑也可能继续生产，但储备与就业会受影响。
3. **研究与切换生产方式。** “科技”研究机械工具后，在建筑城市明细切换机械配方；蒸汽配方另需蒸汽动力。新方式同时改变原料、岗位数量和技工比例，不能只看更高的产量数字。被禁用的按钮显示技术条件，资格不足会限制招聘。
4. **推动教育。** “政治 → 法律”选择教育制度，查看支持与反对，再提出法案。法案经过阶段审议，可能受挫或失败；不能付一笔钱立即获得法律。通过相关法律后，到“机构预算”提高教育等级，承担扩编费、官僚点与每日费用，识字率随时间改变。

这些是本项目的游戏路线，人口、制度分类和经济参数均为场景简化，不是清代账册或精确制度复原。

## 建设、投资和铁路

“建筑”页支持搜索、地区和行业分类；点击建筑名称展开城市，“＋”进入选址。政府项目加入全国队列，排队时不预扣整笔工程款，施工期间按实际能力支付材料与营建工资。队列每页 8 项，可调整政府项目顺序、暂停、恢复或取消；已经发生的施工支出不退还。

私人投资池来自私人所有等级的盈利分红，投入比例受经济法律影响。系统按盈利及劳工条件自主安排私人项目，项目与政府建设共享能力；私人费用由投资池支付。到“建筑 → 建造队列”查看资金和整体暂停／恢复私人投资。政府暂停不会等同于停止私人投资。

扩建营建部门可增加能力；材料短缺、工人不足与资金也会限制施工。营建部门的木架／铁架方式会改变材料和工资需求。

铁路在“市场 → 地区价格与接入”或“省份 → 本地价格”安排。需掌握铁路技术，省内须有可建设城市。点击“加入铁路建设 · 160点”加入真实政府队列，**完成后**增加 20 基础设施；同省已建与在建合计最多 20 级。铁路运营继续消耗煤、工具及工资，不是即时购买基础设施。

## 怎样读经济数字

| 页面 | 数字含义 |
| --- | --- |
| 建筑列表右上金额 | 最近一日利润，已扣投入成本及实付工资；亏损为红色 |
| 建筑展开详情 | 实际就业／岗位、配方、工资、储备、债务、分红、公私等级 |
| 市场价格偏离 | 相对该商品基础价格的涨跌 |
| 本地价格偏离 | 相对全国市场价格的涨跌 |
| 短缺减产 | 使用该商品的产业受到的供给不足惩罚 |
| 人口税后收入 | 该阶层扣税后的每日总收入；消费和缴税单列 |
| 人口财富与识字率 | 按人口加权的群体平均值，阶层人口包含家属 |
| 私人投资池 | 私有分红投入的资金，与国库分开 |

人口页可选全国或地区，分别查看农民、劳工、技工、店主、资本家、贵族、失业者。低消费满足和财富下降会增加激进派；农村居民也有生产、收入与消费。

## 政府、法律与机构

“政治”页面的法律区提供 8 组、25 项法律选项。每组只有一项现行法律，提出新法不会立即替换。顶部显示审议阶段、支持、反对与挫折；政府缺乏支持可能使审议停滞，法案也可以撤回。

“组阁与利益集团”可选择 1—4 个集团组成政府，提交改组后有冷却。政治力量受职业、财富和法律影响，合法性同时考虑集团支持及分歧。“机构预算”控制教育、警务、劳动监察和医疗，受法律开放等级、官僚容量和财政限制。投票法律目前改变政治权重，尚没有完整政党选举流程。

## 地图、城市和人物

底部切换国家、省份、经济、人口与地形视图。地图右键拖动或 W/A/S/D 平移，滚轮缩放。点击大清省域进入概览、建筑、人口、本地价格、信息五页；城市“进入”打开三维场景，住宅／工业／行政／滨水按钮移动视角。城市和人物按右键环绕，滚轮调整距离。

点击已模拟外国可查看其经济和领袖，再开始三维会谈。正式提案才会改变关系、资金或贸易协定，受到可执行条件与冷却限制；对白是按状态编写的游戏回应。会谈期间保持日期不变，结束后才能继续推进。

全球底图有 314 条参考记录，但只有 12 国接入经营。疆域依据 1815 年资料，不是 1836 年精确边界；大清省界、三维城市、人物容貌与风景均存在示意和题材诠释。大清黄龙识别旗采用晚清图式。未实现战争和征服、完整条约、世界市场 Merchant Marine、文化宗教人口、完整历史及 DLC 内容，战役也尚未延伸到 1936 年。

## 保存与运行

F5 保存、F9 读取，手动槽通常位于 `%APPDATA%\Godot\app_userdata\Sovereign — The Industrial Century\campaign.json`，上一份保留为 `.bak`。

0.10 写入第 6 版存档，有效第 1—5 版存档会迁移。迁移保留旧日财务快照，补齐新账户和制度，下一日改用新经济规则；不会补算过去历史。旧库存仅保留兼容用途。新版存档不能交给仅支持旧格式的程序，跨版本前保留原文件副本。

正常游戏无需安装开发工具或联网。历史来源链接会打开网页。默认 Forward+，遇到兼容问题可使用同目录 `Sovereign-Compatibility.cmd`，图像效果可能不同。实际验证记录见 [TEST-REPORT.md](TEST-REPORT.md)，详细范围见 [README.md](README.md)和 [RELEASE-0.10.md](RELEASE-0.10.md)。
