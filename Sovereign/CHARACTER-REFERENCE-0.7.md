# 道光人物对照与重做记录

对照来源：用户电脑上实际运行的《Victoria 3》中文版本，大清国家信息 → 道光人物概览。观察时游戏暂停，显示1838年8月28日。只观察渲染结果，没有提取原作角色文件。

| 部位 | 原版可见特征 | 0.6问题 | 本轮处理 |
| --- | --- | --- | --- |
| 身形 | 瘦长站姿、肩腰区分、两臂垂于身侧 | 宽圆半身躯干，腹前U形袖子 | 完整长袍身形，单独肩、胸、腰、髋裁片，重新绑定双臂 |
| 服装 | 深色绣披领、金色立领、龙纹衣身、腰带、袖口与佩饰分层 | 单一浅纹大袍，缺少腰线和披领 | 各层有独立几何，增加金底与深蓝底刺绣材质 |
| 手部 | 放松下垂，袖口与手背衔接 | 双手悬空、手指张开、腕缝明显 | 重新确定手腕和掌面方向，调整袖口开口与手指 |
| 显示 | 深色帷幕，人物轮廓清晰 | 明亮地图背板，半身取景切掉衣服 | 深红帷幕、柔光，按模型尺寸设置全身和近景镜头 |
| 动作 | 有生命感的头、身与手臂动作 | 基础动作已存在，但身体姿态僵硬 | 保留骨骼/表情，重新定义下垂手臂的静止姿态，修正手势叠加 |

视觉检查中发现并迭代了过深披领、袖子均匀环状褶皱、纹样横向拉伸、手指穿袖和腰佩位置与侧缝纹样拉伸。正面、侧面、背面、近景以及实际动画均需以游戏渲染验收，Blender中的效果不能代替游戏检查。

本轮仍是原型美术改进：没有达到原作一模一样的角色品质。脸部雕刻、头发和胡须、真实织物材质、布料运动及历史服饰考证仍有差距。新全身服装只覆盖道光，其余角色覆盖情况见 Assets/leaders/README.zh-CN.md。
