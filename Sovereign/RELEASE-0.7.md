# 0.7：道光三维人物重做

本轮针对身体比例和衣服造型，按实际运行的《Victoria 3》道光人物页面研究肩线、腰身、垂臂姿态和服装层次。代码与资产独立制作，使用现有人体基础资产和原创服装网格。

- 重建道光身体与自然垂臂姿势，重新设计服装层次，保留眨眼、呼吸、头部与会谈动作。
- 袍服UV按真实截面弧长展开，腰部切成独立UV岛，避免侧缝和腰带下的刺绣拉伸。
- 取景支持全身、常规和面容；镜头读取模型实际包围盒，不再把全身模型套入旧半身镜头。
- 右键可环绕人物；布景与照明随观察方位移动，避免镜头穿到背景墙后。
- 调整柔光与深红帷幕，减少背景抢眼的亮色块；原有187块独立地砖合为单一地面。
- 手势在每帧恢复基础姿态后叠加，兼容没有逐帧前臂轨道的模型，避免累计扭转。

经济、省份、外交和存档格式沿用0.6，当前仍为第5版存档。可玩范围仍为12国、128城和1836—1846战役。没有把本轮人物重做当成全世界人物全部完成；当前成品仍与《Victoria 3》的商业美术质量有差距。

验证结果见 TEST-REPORT.md；上一版本记录保留在 TEST-REPORT-0.6.md。
