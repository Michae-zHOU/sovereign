# 大清开发界面 · 0.6

大清发展入口由 [`Presentation/QingDevelopment.cs`](Presentation/QingDevelopment.cs) 提供。在 `Main.Overview()` 开头调用：

```csharp
if (_engine.Player.Id == "QNG") { QingOverview(); return; }
```

界面使用紧凑的圆形导航、两排指标、酒红标题和灰蓝纹理面板。大清概览显示按当前日期查得的在位君主、财政、人口、就业和三项可操作的发展方向。0.5 以全国建造力与持续施工成本替代每城独立倒计时，存档升级为第 4 版，兼容读取第 1、2、3 版；既有历史事件保留。

| 方向 | 读取的数据 | 真实操作 |
| --- | --- | --- |
| 广州商贸与粮食供应 | 全国粮价、贸易前产需差额、1836 开局粮价 | 广州城市详情、全国市场的进口与出口管理 |
| 苏州织造与城镇就业 | 苏州纺织等级、建设队列、待业人数 | 苏州三维场景；调用 `BuildInCity("QNG_suzhou", "textile")` 加入全国政府队列，排队不预扣整笔造价，施工时持续结算 |
| 兴办初等教育 | 全国识字率、教育改革施行状态 | 人口面板；调用 `EnactReform("primary_schools")`，支付初始资金并产生日常费用 |

所有开局对照来自一次独立、从不推进的 `SimulationEngine.NewGame("QNG")` 状态。读档后仍对照同一版 1836 年场景，不以打开界面的时刻重设基线。箭头只比较实际状态，不代表目标完成度。没有新增虚构的日记进度、官僚资源、法律辩论、海关系统或未实现的战争操作。

## 施工与人物呈现

苏州发展卡显示纺织厂所需建造点和全国施工方式；它是一个地点明确的快捷入口。完整建造页由 [`Presentation/ConstructionInterface.cs`](Presentation/ConstructionInterface.cs) 提供“建筑 → 城市选址 → 全国队列”流程，队列每页 8 项，并提供营建部门管理。暂停、优先级、缺料与营建就业会影响工期；施工参数及未实现的私人投资见 [建造系统对照](CONSTRUCTION-REFERENCE.md)。

0.6人物查看与外交会谈默认使用真实三维网格。道光及4位英国、日本领袖新增人体拓扑、皮肤纹理、骨骼与表情；其余人物仍为可动风格化模型。大清朝廷、国家概览和人物档案使用独立视口的实时三维预览；旧二维肖像只保留为历史版本美术文件，不再作为人物界面默认。模型不是经考证的本人容貌复原。

## 历史与模拟的边界

- 在位皇帝来自现有 `HistoricalLeaders` 日期表。道光帝的历史依据沿用 [故宫博物院的宣宗条目](https://www.dpm.org.cn/court/lineage/226239.html)，详见 `HISTORY-SOURCES.md`。界面不把公历年份直接换算为农历年号年份。
- 广州商贸的选题依据是其在当时中外贸易中的地位；[广州市政府发布的十三行历史介绍](https://www.gz.gov.cn/zlgz/whgz/content/post_8149163.html) 记述了 1757—1842 年广州十三行对欧美通商的制度背景。只将这一事实用作内容选题，未声称当前全国贸易模型已经实现十三行制度。
- 苏州产业建设和初等教育改革是当前游戏规则下玩家可选的政策方向，不是对 1836 年实际工业规模或清政府当时教育政策的复原。
- 当前大清有 40 个已选城市、3 个场景地区，全局共有 128 座城市。新增聚落的历史依据与近似位置见 `QING-SETTLEMENT-SOURCES.md`。人口、行业、地区划分、价格与财政是场景作者的游戏估计，不是人口普查或清代账册。全部历史聚落仍是后续内容目标。
- 财政沿用全游戏共用的抽象 `£` 计价；没有把现有经济数字重新标成清代银两或宣称具有真实币值。

历史资料核对日期：2026-09-19。

## 40 城市扩展与旧存档

新游戏保留全国初始人口和既有六类产业总等级，将原有产能分配到 40 座城市。0.5 另在北京设置 3 级初始营建部门，岗位需要由实际劳动力填补。每座城市参与本地劳动力、生产、全国工程选址、人口增长和迁移计算。三维资源依旧在进入该城时按需读取。

载入第 2 版存档时，原有 8 座大清城市的完整状态、建设队列和全国资金、商品、生产、政策、研究、外交等记录保留。新增 32 个聚落的人口从其所在地区已有农村人口中转入，地区人口与全国人口精确守恒；新增聚落不赠送工业等级或产出，可由玩家建设。现有城市的历史与新版本开局产业分布因此可能不同。界面的“开局”对照始终指当前版本的新游戏场景，而非旧版存档的原始分配。

第 1 版存档继续保留其原有三国玩家状态，加入其余国家时采用当前场景基线。第 1、2、3 版的旧工程按照原倒计时完成比例迁移为建造点，保存已预付款标记，不二次收取材料费；不会赠送营建部门。第 4 版保存队列顺序、进度、暂停、营建等级与生产方式，旧版游戏不能读取第 4 版存档。

## 0.6省份与外交

大清由三个粗分大区拆为18行省及9边疆管理区；全27区支持省域点选、人口和城市列表。详见 [省份说明](QING-PROVINCE-SOURCES.md)。写入第5版存档，保留第1–4版迁移。外国国家详情接入会谈，外交条件与命令执行一致，相关变更在 [0.6发布记录](RELEASE-0.6.md)。
