# 0.6 界面观察与实现

2026-09-19对照用户电脑中运行的《Victoria 3》中文界面，读取可见画面、只读查看GUI布局参数，并查阅[Paradox官方UX开发日志74](https://www.paradoxinteractive.com/games/victoria-3/news/dev-diary-74-ux-improvements)。本地参考中可见法律管理页和政治地图；未改动原游戏文件、未提取或分发原作图像或界面资产。原作内的图标、绘画和雕塑细节没有被宣称为本项目已经完成。

| 观察到的设计 | 当前实现 |
| --- | --- |
| 棕色仪表顶栏、两排紧凑指标，日期速度独立在右 | 六项真实国家指标，点击进入对应管理页 |
| 窄竖排圆形导航、灰紫管理背景、棕色按钮 | 原创SVG皮肤、可收起详情页、较宽的省份与国家详情 |
| 国家详情横向分页，外交不可执行条件可见 | 概览/外交/领袖；费用、冷却、关系门槛直接显示；与执行复用规则 |
| 羊皮纸政治地图、深色国名字体、边框强调 | 国家及省份采用纸色；省份分色与选中强调；独立地形模式 |
| 底部连体地图工具、右侧分节事务栏 | 国家/省份/经济/人口/地形；真实建设队列、研究、重点城市 |

新增省份层与三维领袖会谈是本项目的功能设计，不声称是原作提供完全相同的对话玩法。对白为本地预设文本，依据当前关系、贸易协定与军事动员状态选择，正式提案实际改变经济状态。

本轮原创SVG仍是简化矢量图标，离原作手绘浮雕图标、细密纹样、角色美术和完整信息密度有差距。世界地图资料年份、地区模拟覆盖和场景估计均在产品内显示。

用户再次明确要求现场比较后，实际打开了其暂停在1838年8月9日的游戏，依次查看大清国家的互动页、信息页和道光人物详情。确认原作人物在左侧面板中实时显示，地图一直保留；原作还具有精细清装与佩饰、浮雕小图标、官僚/权威/影响力等专用指标、折叠外交行为分组、地区边线与占领纹理。

据此新增缓存的独立SubViewport人物预览，接入大清朝廷、外国国家概览和领袖档案。预览使用与会谈相同的真正三维网格及动画，保持世界地图可见；只在显示时绘制，避免面板刷新反复创建角色。独立可转动的会谈视图仍保留。完整原作指标、资产精度和全部外交制度本轮没有实现，不用虚构数值填充界面。
