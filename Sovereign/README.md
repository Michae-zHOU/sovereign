# 万国纪元：工业世纪 — 大清篇 0.14

**中文 Windows / Godot 开发版。** 本轮补齐政治、人口、外交和八类建筑的图文识别，并根据本机 Victoria 3 实际操作观察改进页面布局。政治概览显示缓存实时三维领袖，人口提供阶层概览与七职业明细，建筑行采用左图右操作。详见[0.14变化与截图](RELEASE-0.14.md)、[实际验证](TEST-REPORT.md)与[后续接续点](PROGRESS.md)。

本地运行 `Sovereign-Windows-0.14/Sovereign.exe`，保留相邻的 `data_Sovereign_windows_x86_64` 文件夹。源码仓不包含Windows发行二进制；自行构建见[BUILD.md](BUILD.md)，操作见[开始游戏](开始游戏.md)。

人物沿用[0.13道光版本](RELEASE-0.13.md)，当前共20个历史身份、21个全身骨骼GLB；本轮没有重制人物。新增人口职业图是二维插画，不替代历史领袖三维模型。经济与政治沿用[0.10机制](RELEASE-0.10.md)，仍为原创简化规则，尚未达到Victoria 3的美术质量或机制完整度。

## 从哪里操作

- **建筑 → 点击建筑名称展开城市**：查看实际就业、工资、利润、现金、债务、分红及公私等级；点击生产方式按钮切换配方。技术未解锁的按钮显示原因，技工资格不足会限制就业。右上金额是最近一日利润，收入和配方变化在下一日结算反映。
- **建筑 → ＋ → 城市选址**：加入政府建造队列。排队不预付整笔造价，施工按实际能力结算材料和工资；营建部门、政府项目、私人项目共同使用全国建造能力。
- **建筑 → 建造队列**：查看政府与私人出资、投资池及工期。政府项目可排序、暂停和取消；私人投资自主选择盈利且具备劳工的产业，可整体暂停或恢复。私人支出来自投资池，完工产生私人所有等级。
- **市场 → 市场订单**：查看每日买卖单、市场价格、相对基础价的偏离和短缺减产，调整商品进出口方向。贸易是简化全国政策，尚非原作世界市场。
- **市场 → 地区价格与接入**，或**省份 → 本地价格**：比较当地价格与全国价格，查看基础设施及市场接入。研究铁路后可将 160 点铁路项目加入政府队列；完成才增加基础设施，随后持续支付运营费用。
- **人口**：在全国与地区之间切换，查看七阶层人口、财富、识字率、税后收入、消费、缴税、需求满足和激进派。省份“人口”页显示该地区的同类数据。
- **政治 → 法律**：查看现行法律、支持和反对，提出法案并推进日期。法案经过阶段审议，可能推进、辩论或受挫，也可撤回。
- **政治 → 组阁与利益集团／机构预算**：改组政府、观察合法性；通过相关法律后配置教育、警务、劳动监察及医疗机构。机构需要官僚容量、扩编资金和持续日支出。
- **政治 → 财政**：查看税收、关税、政府分红、公共支出和私人投资池，调整税率。

地区的农村人口也有自给生产和收入。地方生产与全国订单共同影响价格；建筑亏损会消耗储备、形成债务并影响就业。当前职业比例、配方、价格曲线、资格、投资选择、政治权重与立法概率均为本项目的简化平衡参数。

## 界面与快捷键

左栏依次为朝政、政治、建筑、市场、人口、科技、外交、日志、地区、领袖，悬停展开名称。详情标题的圆形“×”关闭面板。顶部图标数字可点击，右侧国家事务可折叠；底部五个圆形按钮切换国家、省份、经济、人口与地形地图。

| 操作 | 用途 |
| --- | --- |
| 空格／独立“Ⅱ”按钮 | 暂停、继续 |
| 弧形表盘 Ⅰ—Ⅴ | 每秒推进 1、2、4、8、12 天 |
| +1天 | 推进一天，观察新结算 |
| 地图右键拖动、W/A/S/D、滚轮 | 平移与缩放 |
| 城市／人物视图右键拖动、滚轮 | 环绕与镜头远近 |
| F1 | 政治页面 |
| F5／F9 | 保存／读取 |
| Esc | 关闭普通弹窗或收起详情 |

事件出现时暂停并等待选择。外交会谈锁定当日领袖和日期，结束后才能推进时间；其他人物观察不强制暂停。正常使用 Forward+ 渲染及 4× 抗锯齿，同目录 `Sovereign-Compatibility.cmd` 提供兼容渲染，效果可能不同。

领袖页面提供**全身、常规、面容**三档取景；面容镜头依据脸部网格定位。小肖像也显示可动模型，同一视图重复显示相同人物与年龄阶段时复用已载入模型。伊莎贝拉在游戏年龄达到 **11 岁**时，从 5 岁造型切换到 13 岁造型；这是两个固定美术阶段，没有逐年衰老或连续年龄变形。服装、发型、儿童比例与历史相似度仍需进一步人工校订，详见[模型说明](Assets/leaders/README.zh-CN.md)。

## 地图、历史与尚未完成的系统

全球地图来自 **1815 年参考底图**，含 314 条国家、政权和历史地区记录，其中一条未分配；这不是 314 个可玩国家，也不是 1836 年精确疆域。大清省界是原创地理示意；河流采用现代自然地理参考。地图尚不随战争、日期自动重画历史边界。

外交已有关系、冷却、贸易协定标记、压力行动和可动三维会谈，但**战争、军队、前线、征服和完整条约体系未实现**。世界市场自主贸易中心、Merchant Marine、海运距离及通行费，文化与宗教人口、完整迁移和歧视系统，政党选举与革命，完整历史事件链、DLC 功能、多人和 1836—1936 全战役仍未完成。现有投票法律改变政治权重，不等于已实现定期选举。

人物身份、任期和部分事件有历史来源；容貌、服装、对白、地区风景及城市街道是题材诠释。省份横幅不是实地历史影像。大清识别旗采用晚清黄龙图式，不能当作 1836 年国旗；美国只实现 1836 年 7 月 4 日由 24 星到 25 星的切换。详情见 [历史来源](HISTORY-SOURCES.md)、[旗帜说明](Assets/flags/README.md)、[地图说明](Assets/map/historical/README.md)及[模型说明](Assets/leaders/README.zh-CN.md)。

## 存档

0.13 沿用 0.10 引入的 **第 6 版存档**，接受校验有效的第 1—5 版存档并迁移。旧版的人口地理、预付工程和大清省份迁移规则仍保留；从第 5 版迁入时补齐订单、人口阶层、生产账户、法律和机构，旧已取得改革映射为对应法律与机构。迁移保留旧日的财务、价格和产出快照，**下一日按新经济规则结算**，不会补算整个历史时期。旧库存字段为兼容保留，不再决定现行价格或作为工业投入扣减仓库。旧程序不能读取第 6 版格式。

手动槽通常在 `%APPDATA%\Godot\app_userdata\Sovereign — The Industrial Century\campaign.json`，保存保留上一份 `.bak`。跨版本使用前保留原文件副本；加载失败不会替换当前战役。
