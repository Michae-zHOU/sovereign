# 万国纪元 · 大清篇 0.4

本版将国家管理移到左侧抽屉，并围绕大清经营补充内容。Windows 界面默认简体中文，开局选择默认为大清；支持超宽窗口展开。

## 界面与操作

- 窄图标导航、可收起的左侧详情面板、勃艮第红标题与铜金边框，顶部紧凑国力指标，右侧建设／研究／城市事务栏，底部地图视图。
- 顶部指标、事务栏项目和城市名称可点击；从三维城市或领袖切回管理页时恢复地图。
- 大清朝政展示真实财政、人口、城镇就业，并提供广州市场、苏州织造和初等教育三个实际操作方向。
- 界面结构参考 Paradox 的 [Graphic Overview](https://www.paradoxinteractive.com/games/victoria-3/news/dev-diary-49-graphic-overview) 与 [UX Improvements](https://www.paradoxinteractive.com/games/victoria-3/news/dev-diary-74-ux-improvements)。图标、纹样、代码与面板为本项目制作；本版不是逐像素复刻，也未达到完整商业游戏的美术或系统规模。

## 城市与世界选择

大清从 8 城增至 **40 城**，总计 **128 座模拟城市**。新增城市参与人口、就业、生产和建设，并按需打开三维场景；包括成都、重庆、武昌、长沙、济南、开封、宁波、厦门等。全国原有起始人口和产业总量保持，新增城市分配其中的份额，未凭空增加全国生产能力。

政治地图新增历史疆域颜色与边线。点击通过地形交点、经纬度和多边形内点判定处理；海洋不再选择最近的首都。全球索引支持搜索和定位。

**疆域资料为 1815 年参考底图，不是 1836 年精确边界。** 314 条资料包含 313 个具名国家／政权／文化地区，以及一条未标注地区记录；151 个专名仍以待校译编号显示。只有原有 12 国接入国家经济模拟，其他条目可选择与查阅，但不能开始完整国家战役。资料不会随日期或外交改变。

经济／人口视图的城市标记大小和数值来自实际本局城市产值／人口，地形视图隐藏政治填色。资料及独立许可证见 [历史底图说明](Assets/map/historical/README.md)。

## 性能与修正

- 顶栏与商品指标复用标签；不再每个模拟日销毁并新建整排控件。
- 国家圈选复用两种材质；城市定义按 ID 缓存，减少逐帧遍历查找。
- 标签遮挡检查限制到每秒 12.5 次；疆域选择使用 5°空间索引缩小候选集合。
- 细节场景仍仅保留当前访问城市，避免一次加载所有城市场景。
- 城市经济摘要推进时间时刷新，国家下拉框展开期间不重建；搜索输入不再触发空格暂停；打开弹窗时顶栏立即显示暂停。

短测结果与环境见 [TEST-REPORT.md](TEST-REPORT.md)，没有用瞬时帧率代替最低配置或长期性能验收。

## 存档

存档升级为第 3 版，可读取有效的第 1、2 版存档。第 2 版迁移保留大清原八城的全部数据、国家资源与建设队列；新增城镇人口从所在地区农村转入，人口守恒，新增城镇没有免费产业。详情见 [开始游戏.md](开始游戏.md)。旧程序不能读取第 3 版存档。
