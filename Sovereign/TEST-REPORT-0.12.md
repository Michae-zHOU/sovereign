# 0.12 人物与发行验证

验证日期：2026-09-20。环境：Windows、Godot 4.5.1 .NET、.NET 8.0.425、Forward+、NVIDIA GeForce RTX 3080 Ti。本轮重做道光的模型、皮肤法线、胡须、眼球动作和部分服饰，同时调整共用人物灯光；其余19个历史身份沿用0.11模型。经济与政治核心没有改动。

## 最终构建与导出

- Debug构建及包含最终动画录制参数的ExportRelease构建均为0警告、0错误。
- Godot导入成功。最终Windows导出退出0，运行时目录包含186个文件；导出程序集与最终ExportRelease程序集SHA256一致，包含新增的 `--leader-clip-detail` 参数。
- 曾出现Godot发布器误用本机.NET 6的问题。最终导出显式设置子进程PATH，直接调用Godot实际引擎，日志确认发布器使用工作区.NET 8.0.425。记录见 [export-sdk-selection-0.12.json](QA/export-sdk-selection-0.12.json)。没有修改系统PATH或注册表。
- 工作区验证仅为子进程重定向AppData。部分启动仍报告 `Failed to read the root certificate store`，属于受限环境诊断；模型、烟雾、截图、录制与性能检查没有发现其他 `ERROR:`。未将这些日志写成“stderr为空”。

该进程结束时报告显存约1.602GiB，包含整个进程、渲染器及资源生命周期，不是单个人物独占显存。无头验证的GPU计数记录为null，不用于性能结论。

## 视觉检查与范围

对比0.11相同取景的原生截图，确认道光眼球大面积白色反射、直线刷束胡须与肩袖外露方块得到修正，面颊更瘦并增加眼周和鼻唇体积。最终GLB已在Godot中重新检查，未用Blender预览代替游戏结果。另检查英国、奥斯曼和西班牙代表人物，未观察到共用灯光调整导致的新缺失材质或大面积过曝。

当前皮肤纹理仍显粗糙，色彩变化和真实皮肤层次不足；帽沿、披领和衣料仍有程序建模的僵硬感。细毛、动作穿插及历史相似度还需逐项改善。自动检查通过不等于人物审美达标，也不证明所有角度都没有穿插；本轮尚未达到Victoria 3的成品人物质量。

历史依据和不确定部分见 [道光造型说明](Assets/leaders/source/DAOGUANG-ART-DIRECTION-0.12.md)。目前范围仍为12国、60地区、128城、20个历史身份、21套模型、6商品及1836—1846战役。本轮未重跑独立经济长程测试或兼容渲染器，没有宣称完成全游戏回归；0.10的36组模拟测试仅作为旧基线。上一轮记录保留在 [0.11验证](TEST-REPORT-0.11.md)。
