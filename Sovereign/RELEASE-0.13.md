# 0.13：道光肤色、胡须与织物调整

本轮仅继续修改道光。其他19个历史身份的20个模型沿用0.11，总量仍为 **12国、20个历史人物身份、21个全身骨骼GLB、1836年1月1日至1846年1月1日**。伊莎贝拉二世的儿童与少女阶段各占一个模型。可玩国家、城市、年代和游戏系统没有扩展。

正式道光GLB与blend已重建、导入并完成Godot审图。**Windows运行版已完成本轮验收**，运行目录为`Sovereign-Windows-0.13`，使用时保留完整运行时文件夹。分发ZIP与哈希以`outputs/release-manifest-0.13.json`及实际文件为准；后续制作接续点见[PROGRESS.md](PROGRESS.md)。

## 制作变化

- **皮肤底色：**改用CC0 MakeHuman中年亚洲男性的原始皮肤贴图，降低细节法线强度，并减轻胡须根部的大片深色染色。目标是减少近景中被放大的斑驳底色；年龄仍主要由0.12已有的瘦颊、颧骨和眼周形体表现。没有把历史肖像贴到三维脸上。
- **胡须：**重新生成弯曲、逐渐收细的上唇须和下颏须，混合深色、暖色与少量灰色丝束。下颏须的末端可离开皮肤向下延伸，调整须根与皮肤的过渡，避免整片胡须贴在下巴上的刷痕感。密度、弯曲和长度是本项目的美术选择，并非史料能确认的精确复原。
- **帽子：**缩窄金色帽带、降低帽沿和帽顶的反光，给帽带加入织纹与细小起伏；红色丝束沿帽顶表面铺设，替换悬起的直线辐条造型。
- **领口与披肩：**领口改用低反光的赭黄色织物，调整前喉边缘、薄折边和搭接缝；披肩前后中心增加轻微下垂与褶皱，并重做薄包边。制作脚本保留0.12的侧肩避让区域、袖口、手部和靴子，不把这些旧改动重新计作0.13成果。

本轮继续使用道光的11骨骼、待机微视线、眨眼和会谈形变；没有新增骨骼或动作系统。其他模型仍为9骨骼。共用肖像灯光沿用0.12基线，本轮的美术结果仍须在实际游戏灯光下判断。
